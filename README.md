# IRAN PANEL PRO — نسخه نمایشی

پنل مدیریتی فارسی و راست‌چین با HTML، CSS و JavaScript؛ مناسب انتشار رابط کاربری روی Cloudflare Pages.

## اجرا
فایل `index.html` را در مرورگر باز کنید یا سه فایل اصلی را در یک مخزن GitHub قرار دهید و مخزن را به Cloudflare Pages متصل کنید.

## امکانات
- داشبورد آماری و صفحه‌های مدیریت کانفیگ، کاربران، فعالیت‌ها و تنظیمات
- ساخت/حذف/فعال‌سازی کانفیگ‌های **نمونه**
- کپی شناسه نمونه
- ذخیره اطلاعات آزمایشی در localStorage مرورگر

## محدودیت مهم
این پروژه **سرور VPN نیست** و کانفیگ واقعی یا اتصال VPN تولید نمی‌کند. مقادیر ساخته‌شده شناسه/داده نمایشی‌اند و به هیچ سروری وصل نمی‌شوند. برای ارائه اتصال واقعی باید یک سرویس VPN قانونی و سازگار با API مستند، زیرساخت سرور، احراز هویت امن و مدیریت کلیدها به پروژه متصل شود. Cloudflare Pages و Workers به‌تنهایی جایگزین سرور VPN نیستند.

## امنیت
این نسخه صرفاً فرانت‌اند آزمایشی است؛ ورود مدیر، مجوزدهی واقعی، دیتابیس امن و API سمت سرور ندارد. برای استفاده عمومی، اطلاعات حساس یا رمز عبور را داخل فایل‌های فرانت‌اند قرار ندهید.
